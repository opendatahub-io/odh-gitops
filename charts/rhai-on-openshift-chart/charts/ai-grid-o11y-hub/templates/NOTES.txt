  OBC={{ include "ai-grid-o11y-hub.obcName" . }}

    set -euo pipefail
    STORAGE_CREDENTIAL_DIR=$(mktemp -d)
    trap 'rm -rf -- "$STORAGE_CREDENTIAL_DIR"' EXIT
    oc get cm "$OBC" -n "$NS" -o jsonpath='{.data.BUCKET_NAME}' > "$STORAGE_CREDENTIAL_DIR/bucketnames"

    oc get secret "$OBC" -n "$NS" -o jsonpath='{.data.AWS_ACCESS_KEY_ID}' | base64 -d > "$STORAGE_CREDENTIAL_DIR/access_key_id"

      --from-file=bucketnames="$STORAGE_CREDENTIAL_DIR/bucketnames" \
      --from-file=endpoint="$STORAGE_CREDENTIAL_DIR/endpoint" \
      --from-file=access_key_id="$STORAGE_CREDENTIAL_DIR/access_key_id" \
      --from-file=access_key_secret="$STORAGE_CREDENTIAL_DIR/access_key_secret" \
      --dry-run=client -o yaml | oc apply -f -
  )

{{- if .Values.ingest.writer.create }}

Spokes authenticate as {{ include "ai-grid-o11y-hub.writerName" . }}. The chart creates the
identity but cannot mint its token, which is not a declarative object, and no object this
chart renders ever contains it. Mint it here:

  TOKEN_FILE=$(mktemp)
  oc create token {{ include "ai-grid-o11y-hub.writerName" . }} -n {{ .Values.namespace }} --duration=8760h > "$TOKEN_FILE"

It then reaches spokes one of two ways, and you need only one of them.
{{ if and .Values.spokePolicy.enabled .Values.spokePolicy.deliverCredential }}
ACM: the command below puts it in Secret {{ .Values.spokePolicy.credentialSecretName }}, and the
policy delivers it to every selected spoke. Nothing else to do per spoke.
{{- else if .Values.spokePolicy.enabled }}
ACM delivers configuration only: spokePolicy.deliverCredential is false. The credential
must reach each spoke through its existing credential manager; no hub Secret is read.
{{- else }}
ACM: set spokePolicy.enabled and spokePolicy.deliverCredential, then hold it in a Secret this hub's policy reads, which then
delivers it to every selected spoke.
{{- end }}
Directly: hand the file to the ai-grid-o11y-spoke chart on the spoke cluster, which creates
the Secret its collector mounts:

  helm upgrade --install rhoai ./charts/rhai-on-openshift-chart \
    -f docs/examples/values-ai-grid-o11y-spoke.yaml \
    --set-file ai-grid-o11y-spoke.credential.token="$TOKEN_FILE" \
    -n rhoai-gitops --create-namespace

After completing the chosen delivery command, delete the private file: rm -- "$TOKEN_FILE".
Nothing rotates the token and no object reports
its age; treat the expiry as an operational commitment, not a default.
